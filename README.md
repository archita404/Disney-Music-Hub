# ✨ Disney Melodies 🏰🎶

> An enchanted library of magical Disney movie songs — play, sing along with synced lyrics, and journey through every kingdom. 💖

---

## 🎬 About

**Disney Melodies** is a beautifully crafted web app that brings the magic of Disney music to your fingertips. Browse iconic songs from your favorite movies, watch official videos, and follow along with **time-synced lyrics** — all wrapped in a dreamy, animated UI. 🪄

---

## 🌟 Features

- 🎵 **Curated Disney Songbook** — 60+ classics from *Frozen*, *The Lion King*, *Moana*, *Aladdin*, *Encanto* & more
- 📺 **Embedded Official Videos** — streams the original Disney uploads from YouTube
- 📝 **Synchronized Lyrics Panel** — karaoke-style lyrics that follow the beat
- 🎭 **Browse by Movie & Character** — explore Ariel, Elsa, Simba, Mulan, and the whole cast
- 💝 **Favorites** — heart the songs you love
- 🎨 **Magical UI** — pixie cursor, animated background, shimmer effects
- 📱 **Fully Responsive** — magic on any device
- 🪄 **Auto-Fallback Player** — never breaks; finds an alternative video if one is unavailable

---

## 🛠️ Tech Stack

- ⚛️ **React 19** + **TypeScript**
- 🚀 **TanStack Start** (full-stack React framework, SSR-ready)
- ⚡ **Vite 7** — lightning-fast builds
- 🎨 **Tailwind CSS v4** + **shadcn/ui**
- 🎬 **YouTube IFrame API**
- ☁️ **Lovable Cloud** ready

## 🚀 Getting Started

### Prerequisites
- 📦 Node.js 20+ and **bun** (or npm/pnpm)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/disney-melodies.git
cd disney-melodies

# 2. Install dependencies
bun install

# 3. Start the dev server
bun dev

### Then open 👉 http://localhost:3000

📂 Project Structure
src/
├── 🧩 components/    # UI components (SongCard, NowPlaying, LyricsPanel...)
├── 🌐 context/       # PlayerContext (global music player)
├── 💾 data/          # songs.ts, lyrics.ts
├── 🪝 hooks/         # useFavorites, etc.
├── 🛣️  routes/        # File-based routing (TanStack)
└── 🎨 styles.css     # Tailwind + design tokens
